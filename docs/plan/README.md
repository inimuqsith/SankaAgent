# Plan

Setiap pekerjaan non-trivial punya satu plan. Salin template di bawah ke `plan-N.md`, lalu minta persetujuan owner sebelum menulis kode. Status plan: `Draft`, `In Progress`, `Blocked`, `Done`.

## Template

```markdown
# Plan N — Judul singkat

- Status: Draft
- Tanggal:
- Pemilik:

## Tujuan
Satu paragraf. Apa yang berubah dan mengapa.

## Di luar cakupan
Hal yang sengaja tidak dikerjakan di plan ini.

## Rancangan
File yang disentuh, antarmuka, alur data, dan keputusan teknis.

## Langkah
1. ...
2. ...

## Tes
Perintah atau skenario yang membuktikan plan ini bekerja.

## Kriteria selesai
Daftar hasil yang bisa diamati.

## Yang perlu dipahami owner
Konsep atau potongan kode yang sebaiknya dibaca owner sendiri.

## Catatan perubahan
Alasan bila rencana berubah di tengah jalan.

## Hasil
Diisi saat status menjadi Done. Sebutkan tes yang benar-benar dijalankan, atau "belum dites".
```
